=== APFD and FDR Calculation ===

Mathematical Explanation:
APFD is computed using the formula:
  APFD = 1 - (ΣTFᵢ / n·m) + (1 / 2n)

Where:
  - TFᵢ is the position of the first test case that kills mutant i
  - n is the number of test cases
  - m is the number of mutants
